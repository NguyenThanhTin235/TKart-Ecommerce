# TKart Ecommerce Spring Boot

## Mô tả
Dự án backend cho hệ thống thương mại điện tử TKart, sử dụng Spring Boot, JPA, Security, JWT, Swagger, Lombok, ModelMapper, MySQL.

## Cấu trúc thư mục
- src/main/java/com/tkart/ecommerce: Mã nguồn Java
- src/main/resources: File cấu hình, template, static
- pom.xml: Quản lý thư viện Maven

## Chạy dự án
1. Cài đặt JDK 17+ và Maven
2. Cấu hình database trong `src/main/resources/application.yml`
3. Chạy lệnh:
   ```bash
   mvn spring-boot:run
   ```

## Thư viện chính
- Spring Boot Starter Web/Data JPA/Security/Validation/Mail/Thymeleaf
- Lombok, JWT, Swagger, ModelMapper
- MySQL Connector
