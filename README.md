# TKart-Ecommerce

Hệ thống thương mại điện tử gồm backend (Spring Boot) và frontend (React/Vite).

## Backend
- Đường dẫn: `source/backend`
- Xem hướng dẫn chi tiết trong `source/backend/README.md`

## Frontend
- Đường dẫn: `source/frontend`

## Khởi tạo nhanh MySQL

```bash
docker-compose up -d
```
